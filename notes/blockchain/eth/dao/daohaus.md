## Subgraph 查询

The Graph Hosted Service 已于 2024-06-12 停用，上述部署名仅作为历史记录。

- [Graph Explorer](https://thegraph.com/explorer)：查找项目当前维护的部署，确认目标链、schema 和 Subgraph ID。
- [The Graph 查询文档](https://thegraph.com/docs/en/subgraphs/querying/from-an-application/)
  - 生产查询使用 The Graph Network Gateway，需要 API key 和 Subgraph ID：`https://gateway.thegraph.com/api/<API_KEY>/subgraphs/id/<SUBGRAPH_ID>`。
  - Subgraph Studio 端点用于开发测试且有限流，不能直接作为旧生产端点的替代。
- [Hosted Service 停用公告](https://thegraph.com/blog/sunbeam-upgrade-window/)
