接口​

相机系统里的接口通常分成四层：传感器输出图像数据，控制总线配置传感器，摄像头模块再把图像封装成 USB/网络/长距离链路，音频则走独立的音频总线。

接口所在链路传输内容常见使用情况说明
MIPI CSI-2传感器 → SoC/ISPRAW、YUV、RGB 等像素流手机、Raspberry Pi、Jetson、嵌入式 Linux当前嵌入式 raw camera 的主流接口，通常通过 MIPI D-PHY 或 C-PHY，按 lane 扩展带宽
DVP / Parallel传感器 → MCU/SoC并行像素、PCLK、VSYNC、HSYNC/HREFOV7670、OV2640、OV5640、ESP32-CAM时序直观、容易接 MCU，但占用较多 GPIO，分辨率和频率提升后布线与时序压力较大
I2C / SCCBSoC/MCU → 传感器芯片 ID、寄存器、曝光、增益、分辨率、帧率等控制信息几乎所有 raw sensor这是控制总线，不承载完整图像；OmniVision 常称 SCCB，实际电气和时序以 datasheet 为准
SPISoC/MCU ↔ 传感器或桥接芯片配置寄存器，少数模块也传低速图像特定传感器、热成像或小型摄像头模块可作为控制接口，但通常不是高分辨率视频的主像素链路
USB UVC摄像头模块 → 主机UVC 视频帧，可为 YUYV、MJPEG 或其他格式USB Webcam、显微镜、采集卡模块内部通常已经完成 sensor 配置、ISP 和 USB 封装，主机按标准 USB Video Class 使用
Ethernet / GigE Vision摄像头 → 网络主机网络数据包中的视频帧工业相机、IP Camera、多摄像头系统适合长距离和多机部署；RTSP、ONVIF 属于上层协议，不是传感器接口
GMSL / FPD-LinkSerializer → Deserializer长距离串行视频、同步和控制通道汽车环视、机器人、远距离机器视觉通常走同轴线或屏蔽双绞线；主机端解串后常再输出 MIPI CSI-2
SLVS-EC / sub-LVDS传感器 → FPGA/ISP高速原始像素流工业相机、高速采集、定制板卡适合高带宽板级设计，普通 MCU 和 SBC 很少直接使用
I2S麦克风/音频 Codec ↔ SoCPCM 音频采样带麦克风的 USB/网络摄像头、会议设备I2S 是音频总线，不传图像；摄像头的画面仍需同时走 MIPI、USB 或网络链路

常见组合​

传感器级相机

                    ┌─ MIPI CSI-2 / DVP / SLVS-EC ─→ SoC / ISP
Image Sensor ───────┤
                    └← I2C / SCCB / SPI：寄存器、曝光、增益、模式配置
成品摄像头

Image Sensor → ISP / Encoder → USB UVC / Ethernet / GMSL / FPD-Link → 主机
Microphone  ─────────────────────────── I2S ───────────────────────→ SoC

  • Raspberry Pi raw camera：通常是 MIPI CSI-2 + I2C，CSI-2 传图像，I2C 配置传感器；Linux 侧由 sensor subdev、CSI-2 receiver 和 ISP/应用组成。

  • ESP32-CAM：常见组合是 DVP + SCCB，DVP 传像素，SCCB 配置 OV 系列传感器。

  • USB Webcam：主机只看到 USB UVC，sensor 的 MIPI/DVP 和 ISP 通常都封装在摄像头内部。

  • IP Camera/NVR：摄像头内部完成采集和编码，通过 Ethernet 输出 RTSP/ONVIF 等视频流；I2S 可能只用于内部麦克风音频。

  • Raspberry Pi CSI-2 usage：CSI-2、Unicam、I2C/SPI sensor control 和 Linux V4L2 链路。

  • MIPI Camera Serial Interface 2：CSI-2、D-PHY/C-PHY 和嵌入式/汽车/机器视觉场景。

  • OMNIVISION OV7739：并行 DVP、MIPI serial 和 SCCB 的传感器实例。

  • USB Video Class v1.5：USB 摄像头的标准类协议。

  • Linux ASoC Digital Audio Interface：I2S 的音频传输定义。

  • TI FPD-Link III serializer / Analog Devices GMSL cameras：长距离相机 SerDes 链路。

分辨率像素建议

假设门口距离摄像头 3 米：

  • 1080p：一般可以判断是否有人、穿什么衣服。
  • 2K：有更多面部和衣物细节。
  • 4K：适合需要进一步裁切的场景，但增加存储压力。
