# 电机

| en                          | cn                       | notes                                          |
| --------------------------- | ------------------------ | ---------------------------------------------- |
| Outrunner Brushless Motor   | 外转子无刷电机           | 转子在外部旋转，具有高扭矩特性。               |
| Inrunner Brushless Motor    | 内转子无刷电机           | 转子在定子内部旋转，擅长高转速应用。           |
| Sensored Brushless Motor    | 传感器无刷电机           | 内置霍尔传感器以精确感知位置。                 |
| Sensorless Brushless Motor  | 无传感器无刷电机         | 通过反电动势 (Back EMF) 估算转子位置。         |
| Axial Flux Brushless Motor  | 轴向磁通无刷电机         | 磁通平行于轴线，具有极高的功率密度。           |
| Radial Flux Brushless Motor | 径向磁通无刷电机         | 最常见的圆柱形电机设计。                       |
| Coreless Brushless Motor    | 无铁芯无刷电机           | 转子无铁芯，几乎无齿槽转矩 (Cogging)。         |
| Slotless Brushless Motor    | 无槽无刷电机             | 定子无槽，适合高频高速运作。                   |
| Stepper Motor Hybrid        | 步进电机混合型           | 结合步进电机齿槽特性与直流无刷特性。           |
| Switched Reluctance Motor   | 开关磁阻电机             | 转子无磁铁，结构简单且稳固。                   |
| BLDC Trapezoidal Motor      | 梯形波驱动无刷电机       | 采用六步换相控制，常用于低成本应用。           |
| FOC-Driven PMSM             | 磁场定向控制永磁同步电机 | 通过向量控制实现高效精准运行，常用于电动汽车。 |
