# 百家乐

- Baccarat
  - 起源有争议：一说 15 世纪末从意大利传入法国，一说 19 世纪
  - 变体：Punto Banco、Chemin de Fer、Baccarat Banque
  - 现代赌场主流为 Punto Banco - 1940 年代哈瓦那形成，由赌场坐庄
  - Punto Banco 按固定补牌表发牌，投注者没有影响结果的决策
- 小桌 / Mini Baccarat - 荷官发牌，节奏快
  - 常见 9 人参与 - 待核验
- 大桌 / Big Table - 可由玩家持牌、开牌
  - 最多 12 或 14 人 - Wizard of Odds
- 限红 - 每个投注项目有最低/最高注额

## 胜负规则

1. A 为 1 点；2-9 按牌面；10、J、Q、K 为 0 点
1. 闲家和庄家的牌点数相加，以个位数为准 - 如 6+7=13 → 3 点，最大 9 点
1. 谁最接近 9 点即为胜方
1. 相同点数即和局 - 庄/闲注不输不赢（push）

## 游戏规则

### 补牌

1. 从闲家开始交替发牌，闲家和庄家各两张
1. 例牌 / 天生赢家：任一方首两张为 8 或 9 点 → 双方都不再补牌，直接比点
1. 否则按补牌表，闲家先补，每方最多补 1 张
1. 没有任何一手牌超过三张牌

**闲家**

| 闲家首两张点数 | 动作 |
| -------------- | ---- |
| 0-5            | 补牌 |
| 6-7            | 停牌 |
| 8-9            | 例牌 |

**庄家 - 闲家未补牌（停在 6/7）时**

- 庄家规则同闲家：0-5 补，6-7 停

**庄家 - 闲家补了第三张牌时**

| 庄家点数 | 闲家第三张牌为以下点数时庄家补牌 | 否则停牌 |
| -------- | -------------------------------- | -------- |
| 0-2      | 任何点数                         | -        |
| 3        | 0-7、9                           | 8        |
| 4        | 2-7                              | 0、1、8、9 |
| 5        | 4-7                              | 0-3、8、9 |
| 6        | 6-7                              | 0-5、8、9 |
| 7        | -                                | 全部停牌 |

- 看的是闲家第三张牌的点数，不是闲家三张牌的合计
- 庄家补牌规则考虑闲家第三张牌 → 庄注胜率略高，标准玩法庄胜抽水 5%

### 一靴牌

- 常见 8 副牌（每副 52 张，共 416 张）为一靴牌，也有 6 副
  - 澳门法定规章允许 6 至 12 副
- 澳门法定规章：发到割牌（白咭）时，为最后一局或再进行一局，之后重新洗牌
- 平台禁投局数 - 范围见 [边注](#边注)
  - 第21局+，不得投注 大小
  - 第26局+，不得投注 超和
  - 第46局+，不得投注 庄龙宝、闲龙宝、完美对子、任意对子、庄对、闲对
  - 第51局+，不得投注 闲例牌/庄例牌

## 投注项目

### 主要投注

| 投注    | 赔率（净赢）        | 赌场优势（8 副牌） |
| ------- | ------------------- | ------------------ |
| 庄家    | 1:0.95（抽水 5%）   | 1.06%              |
| 闲家    | 1:1                 | 1.24%              |
| 和局    | 1:8                 | 14.36%             |
| 和局    | 1:9（少数场馆）     | 约 4.84%           |
| 庄/闲对 | 1:11                | 10.36%             |

- 8 副牌概率：庄胜 45.86%，闲胜 44.62%，和 9.52%
- 庄胜扣 5% 佣金：押 100 赢 95
- 和局时庄/闲注退回，或按场馆规则保留/改注
- 庄/闲对 - 首两张牌牌面等级（rank）相同即可，不计花色；J+J 算，J+Q 不算（两者都是 0 点）
- 路单只是记录；有限牌靴不放回发牌，各局概率会稍有变化，但跟路/反路不能带来可靠优势

**超级六 / Super 6**

- 免佣玩法：庄胜不抽水；庄以 6 点胜，赔 50%
  - 庄注赌场优势约 1.46%；标准 5% 抽水为 1.06%
- 边注：庄以 6 点胜出才中，赔率依场馆

### 边注

:::caution

- 边注赔率、禁投局数依平台，不属于 Punto Banco 通用规则
- 下列示例赔率与第 21/26/46/51 局限制的具体平台来源待确认
- 闲例牌 / 庄例牌的 1:4 赔率待核验

:::

| bet      | rate | 备注                                           |
| -------- | ---- | ---------------------------------------------- |
| 闲对     | 11   | 澳门法定规章 1:11                              |
| 庄对     | 11   | 同上                                           |
| 大       | 0.5  | 其他平台见到 0.54（Playtech）、0.48（Triple-PG） |
| 小       | 1.5  | Playtech 1.5，赌场优势 5.28%                   |
| 任意对子 | 5    | Playtech 1:5，6 副牌赌场优势约 14.5%           |
| 完美对子 | 25   | 8 副牌赌场优势 13.03%                          |
| 闲例牌   | 4    | 待核验                                         |
| 庄例牌   | 4    | 待核验                                         |
| 超和 N   |      | 赔率按和局点数而定                             |

- rate 为净赢赔率
- 大小 - 本局共 4 张牌为小，5 张或 6 张牌为大
  - 8 副牌：4 张 37.89%，5 张 30.34%，6 张 31.77%
- 任意对子 - 庄或闲任一方首两张牌成对
- 完美对子 - 庄或闲的前两张牌必须同花同色同数字或同英文字母
- 闲例牌/庄例牌边注 - 一般指该方以例牌（8 或 9 点）胜出才中；具体结算以平台规则为准，例牌本身不要求胜出
- 超和 - 庄和闲为和局时，押中和局点数
