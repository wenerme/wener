# 下载器

- [zerx-lab/FluxDown](https://github.com/zerx-lab/FluxDown)
  - AGPL-3.0，Rust 驱动的多协议下载管理器。
  - 支持 HTTP、FTP、BitTorrent / 磁力链接及 HLS / DASH 流媒体。
  - 提供多线程下载与浏览器集成；下载内容仍需具有相应访问和使用权限。
- [aria2](./aria2.md)
  - GPLv2, C++
- [transmission](./transmission.md)
  - GPLv2, GPLv3, C++
- [qBittorrent](https://github.com/qbittorrent/qBittorrent)
  - GPLv2, C++
- 平台下载
  - [youtube-dl](./youtube-dl.md)
- rclone
- [e-alfred/ocdownloader](https://github.com/e-alfred/ocdownloader)
  - AGPLv3
  - for Nextcloud using ARIA2
