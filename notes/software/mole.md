# Mole

```bash
brew install mole
```

| 功能         | 命令           | 用途                     |
| ------------ | -------------- | ------------------------ |
| 交互式菜单   | `mo`           | 选择清理功能             |
| 深度清理     | `mo clean`     | 清理缓存、日志、遗留文件 |
| 卸载 App     | `mo uninstall` | 卸载应用及相关数据       |
| 磁盘分析     | `mo analyze`   | 定位占用空间的文件       |
| 系统维护     | `mo optimize`  | 清理和重建部分系统缓存   |
| 开发环境清理 | `mo purge`     | 清理项目构建产物         |
| 安装包清理   | `mo installer` | 查找安装包               |
| 系统监控     | `mo status`    | CPU、GPU、内存、磁盘监控 |
