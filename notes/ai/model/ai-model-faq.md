# AI Model FAQ

## Taxonomy

- Provider-Agnostic Model Taxonomy / 厂商无关的模型分类体系
- auto
  - 有些 Harness 会支持 auto 来在请求的时候自动选择

| Tier     | 含义 | 典型用途                                   |
| -------- | ---- | ------------------------------------------ |
| nano     | 微型 | 固定标签分类、字段提取等边界明确的高频任务 |
| lite     | 轻量 | 简单交互、短文摘要、规则明确的任务         |
| standard | 标准 | 通用对话、常规代码与文档任务               |
| pro      | 专业 | 多步骤分析、跨文件修改、需要反复校验的任务 |
| flagship | 旗舰 | 目录内优先用于高难度、高质量要求的任务     |

| Role         | 含义   | 职责                         | 推荐 Tier 起点  |
| ------------ | ------ | ---------------------------- | --------------- |
| orchestrator | 协调者 | 分派任务、协调依赖、汇总结果 | standard / pro  |
| planner      | 规划者 | 拆解目标、安排步骤和检查点   | standard / pro  |
| worker       | 执行者 | 完成分配的子任务、交付结果   | lite / standard |
| reviewer     | 审查者 | 对照要求查错、核验关键结论   | standard / pro  |
| researcher   | 研究者 | 检索资料、核对来源、综合证据 | standard / pro  |
| summarizer   | 摘要者 | 压缩上下文、保留关键信息     | lite            |
| router       | 路由器 | 识别请求类型、选择模型或流程 | nano / lite     |

| Task               | Mean       | 用途                                           | 选型关注点                             |
| ------------------ | ---------- | ---------------------------------------------- | -------------------------------------- |
| general            | 通用问答   | 日常对话、知识问答                             | 指令遵循、事实准确性                   |
| coding             | 编程       | 编程、调试、重构                               | 代码理解、修改正确性                   |
| reasoning          | 推理       | 数学、逻辑、复杂分析                           | 多步推理、结论可核验性                 |
| writing            | 写作       | 写作、改写、文档                               | 表达清晰度、风格和格式遵循             |
| creative           | 创作       | 故事、创意、内容创作                           | 创意多样性、设定一致性                 |
| roleplay           | 角色扮演   | 按角色设定进行多轮对话                         | 角色一致性、多轮连贯性                 |
| prompt-extension   | 提示词扩写 | 为图像、视频生成补充构图、光照、镜头或动作细节 | 保留原意和约束、下游结果与原意的一致性 |
| prompt-compression | 提示词压缩 | 缩短指令或上下文，减少输入 Token               | 压缩率、约束和事实保留、下游通过率     |
| extraction         | 信息提取   | 从输入中提取指定字段                           | 字段准确率、缺失值处理、Schema 遵循    |
| classification     | 分类       | 根据标签集判断类别或分流                       | 标签准确率、边界样本、未知类处理       |
| moderation         | 内容审核   | 按内容政策标记风险类别                         | 分类阈值、漏报率、误报率               |
| vision             | 视觉理解   | 识别并解释图片内容                             | 图像输入、细节识别、空间关系           |
| ocr                | 文字识别   | 将图片或扫描件中的文字转成文本                 | 字符错误率、多语种、阅读顺序           |
| object-detection   | 目标检测   | 输出图像中目标的类别和边界框                   | 定位精度、召回率、小目标表现           |
| image-segmentation | 图像分割   | 按像素划分图像区域，输出掩码或标签图           | 掩码精度、边界质量、实例区分           |
| image-generation   | 图像生成   | 按提示生成图像或局部编辑                       | 图像输出、提示词遵循、编辑区域控制     |
| summarization      | 摘要       | 压缩原文、提炼要点                             | 关键信息保留、不引入原文没有的事实     |
| translation        | 翻译       | 在不同语言间转换文本                           | 语义准确性、术语一致性                 |
| query-rewriting    | 查询改写   | 将口语化或含糊的问题改写成检索词或多个子查询   | 保留原检索意图、检索召回率             |
| search             | 检索       | 查找相关资料或记录                             | 检索接入、结果相关性                   |
| research           | 调研       | 调查问题，汇总多个来源的证据                   | 来源核验、交叉验证、引用可追溯性       |
| embedding          | 向量化     | 将文本或图像编码为向量                         | 输入模态、向量维度、下游检索表现       |
| reranking          | 重排序     | 对已召回的候选结果重新排序                     | 排序质量、候选规模、额外延迟           |
| planning           | 规划       | 任务拆解、制定计划                             | 约束覆盖、依赖顺序、可执行性           |
| tool-use           | 工具调用   | 选择工具并生成调用参数                         | 工具选择、参数正确性、失败恢复         |
| computer-use       | 桌面操作   | 通过鼠标和键盘操作桌面应用，完成跨应用流程     | 界面定位、窗口切换、结果验证           |
| browser-use        | 网页操作   | 在浏览器中导航网页、填写表单、操作 Web 应用    | 元素定位、页面状态跟踪、提交结果验证   |
| terminal-use       | 终端操作   | 执行命令，读取输出和退出状态，再决定下一步     | 命令正确性、错误恢复、结果验证         |
| data-analysis      | 数据分析   | 计算指标、解读趋势                             | 计算正确性、统计解释、可复现性         |
| document-qa        | 文档问答   | 基于文档内容回答问题                           | 证据定位、引用准确性、无依据时拒答     |
| review             | 审查       | 按需求或规范检查内容中的问题                   | 问题检出率、误报率、证据定位           |
| tutoring           | 教学辅导   | 讲解概念、给出练习和反馈                       | 分步讲解、难度适配                     |
| audio              | 音频理解   | 分析语音含义或声音事件                         | 音频输入、语义理解、事件识别           |
| speech-recognition | 语音识别   | 将语音转成文本（ASR）                          | 转写准确率、语言覆盖、时间戳           |
| speech-synthesis   | 语音合成   | 将文本转成语音（TTS）                          | 发音、韵律、首段音频延迟               |
| music-generation   | 音乐生成   | 根据文本或参考音频生成音乐                     | 曲风遵循、段落连贯性、音质             |
| video              | 视频理解   | 分析视频内容和事件                             | 视频输入、时序理解、事件定位           |
| video-generation   | 视频生成   | 根据文本或参考媒体生成、编辑视频               | 视频输出、运动连贯性、主体一致性       |

| Effort  | 含义 | 适用场景或限制                                           |
| ------- | ---- | -------------------------------------------------------- |
| none    | 无   | 显式关闭额外推理；区别于省略参数，也不代表模型支持此档位 |
| minimal | 最小 | 只需少量推理的高频短任务                                 |
| low     | 低   | 规则清晰、步骤少的常规任务                               |
| medium  | 中   | 需要权衡多个条件的常规任务                               |
| high    | 高   | 多步推理、复杂约束或需要复核的任务                       |
| xhigh   | 极高 | `high` 未达到质量目标，且可接受额外延迟与成本            |
| max     | 最大 | 内部最高档；实际支持的档位及其含义按模型和端点映射       |

| Profile      | 类型 | 优先目标或约束                                |
| ------------ | ---- | --------------------------------------------- |
| fast         | 偏好 | 优先降低首包延迟或总响应时间                  |
| balanced     | 偏好 | 在质量、延迟和成本之间取平衡                  |
| quality      | 偏好 | 优先提高目标任务的通过率                      |
| economy      | 偏好 | 达到质量门槛后，优先降低每次成功任务的成本    |
| reliable     | 偏好 | 优先降低失败率和重复运行时的结果波动          |
| long-context | 能力 | 覆盖所需输入长度，并能从长上下文准确提取信息  |
| structured   | 能力 | 支持所需 Schema；JSON 可解析不等于符合 Schema |
| multilingual | 能力 | 覆盖所需语言，并在目标语言上通过任务评估      |
| privacy      | 策略 | 符合部署位置、数据留存和训练用途要求          |
| distillable  | 策略 | 确认许可和服务条款明确允许用输出做模型蒸馏    |
| nsfw         | 策略 | 按具体内容类型确认服务政策和适用法律允许      |
