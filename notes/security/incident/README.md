# 安全事件

- 跨产品、证书信任、软件供应链和大规模安全事件；单个漏洞的技术细节继续放在 [CVE](../cve/README.md)，互相链接
- 每个事件单独记录时间线、成因、影响范围、各方响应、处置和来源；按首次报告日期倒序索引
- 时间注明来源和时区；已确认事实、厂商声明、推断与待验证项分别记录，公告日期不等于事件开始时间
- 事件可以关联多个产品的 CVE / advisory；分别记录 CNA 产品范围与下游引用口径，不把关联编号视为整个事件的统一编号
