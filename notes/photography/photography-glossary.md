# Glossary

| en                 | cn             | meanning                         |
| ------------------ | -------------- | -------------------------------- |
| Photography        | 摄影、摄影艺术 | 用光线记录画面的过程、技术和艺术 |
| Camera             | 相机、摄影机   | 用于拍摄照片或视频的设备         |
| Photograph / Photo | 照片           | 摄影得到的静态影像               |
| Photographer       | 摄影师         | 从事摄影的人                     |
| Take a photo       | 拍一张照片     | 一次具体的拍摄动作               |
| Shooting           | 拍摄           | 可以指拍照片或录视频             |
| Videography        | 摄像、视频创作 | 对应以动态影像为主的创作         |

```
Photography（摄影）
├── Camera（相机工具）
├── Lens（镜头）
├── Light（光线）
├── Composition（构图）
├── Exposure（曝光）
├── Color（色彩）
└── Post-processing（后期处理）
```

```
photo = 光
graphy = 书写、描绘
photography = 用光作画
```
