# Sony A7C

- Sony Alpha 7C II / α7CII / A7C2 / ILCE-7CM2
- 参考
  - https://helpguide.sony.net/ilc/2360/v1/zh-cn/contents/231h_specifications_ilc2360.html

```
ILCE - 7C - M2
│      │    └─ Mark 2，即第二代
│      └─ 7C系列：全画幅紧凑型
└─ Interchangeable Lens Camera with E-mount
   E卡口可更换镜头相机
```

| product      | code      |
| ------------ | --------- |
| Alpha 7C     | ILCE-7C   |
| Alpha 7C II  | ILCE-7CM2 |
| Alpha 7CR    | ILCE-7CR  |
| Alpha 7 IV   | ILCE-7M4  |
| Alpha 7R V   | ILCE-7RM5 |
| Alpha 7S III | ILCE-7SM3 |

- M2 = Mark II，第二代；
- R = Resolution，高分辨率方向；
- S = Sensitivity，视频和高感方向；
- C = Compact，紧凑型；
- L 通常表示附带镜头的套机版本，并不是相机性能不同。
