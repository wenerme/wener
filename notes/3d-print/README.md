# 3D Printing

- 相关领域
  - process - FDM/FFF、SLA/MSLA、SLS 等打印工艺
  - materials - filament、resin、PLA、PETG、ABS、TPU 等材料
  - modeling - CAD、mesh、STL、OBJ、3MF 等三维模型
  - slicing - layer height、infill、support、wall、speed 等切片参数
  - file-formats - STL、3MF、G-code、`.bgcode` 等文件格式
  - printer - motion system、extruder、hotend、heated bed、build plate
  - calibration - bed leveling、flow、temperature、retraction、PID、input shaping
  - printability - overhang、bridge、stringing、warping、layer adhesion、tolerance
  - post-processing - support removal、sanding、curing、painting、assembly
  - hardware - printer frame、stepper motor、nozzle、sensor、controller、enclosure
