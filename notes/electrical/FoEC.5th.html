Charge is an electrical property of the atomic particles of which matter consists, measured in coulombs (C).

一个原子有电子,质子和中子组成.电子携带电荷 e=1.602×10−19Ce = 1.602 \times 10^{-19} Ce=1.602×10−19C, 电子电荷为负点.质子携带等量的正电.等量的电子和质子使原子电荷处于中和状态.

  1. 库伦是一个较大的电量单位.1 C 电量为 1/(1.602×10−19)=6.24×10181/(1.602 \times 10^{-19}) = 6.24\times 10^{18}1/(1.602×10−19)=6.24×1018, 在实际中大多使用 pC, nC 或 μC.
  2. 根据试验观察,自然中发生的电荷均为电子电荷 e=−1.602×10−19e = -1.602 \times 10^{-19}e=−1.602×10−19 的整数倍
  3. 电荷守恒定义说明,电荷不能被创建和摧毁,只能被传输.因此一个系统的电子电荷总量不会改变.

当导线(由原子组成)连接到电池两端(电动势/electromotive force 来源),正电荷往一个方向移动,负电荷往相反方向移动,这样就形成了电流.

An ideal independent source is an active element that provides a specified voltage or current that is completely independent of other circuit elements.

An ideal dependent (or controlled) source is an active element in which the source quantity is controlled by another voltage or current.

four possible types of dependent sources

  1. A voltage-controlled voltage source (VCVS).
  2. A current-controlled voltage source (CCVS).
  3. A voltage-controlled current source (VCCS).
  4. A current-controlled current source (CCCS).

电子原件分为

  • 主动元件（Active components） 是一种电子元件，相对于被动元件所没有的，在使用时它们有增益或方向性。它们包括了半导体器件与真空管。

  1. The power dissipated in a resistor is a nonlinear function of either current or voltage.

A branch represents a single element such as a voltage source or a resistor.

A node is the point of connection between two or more branches.

A loop is any closed path in a circuit.

b=l+n−1b = l + n - 1b=l+n−1

Two or more elements are in series if they exclusively share a single node and consequently carry the same current. Two or more elements are in parallel if they are connected to the same two nodes and consequently have the same voltage across them.

Kirchhoff’s current law (KCL) states that the algebraic sum of currents entering a node (or a closed boundary) is zero.

where N is the number of branches connected to the node and is the nth current entering (or leaving) the node.

N 个连接到节点的分支, in 为第 n 个元件进入或离开该节点的电流.

The sum of the currents entering a node is equal to the sum of the currents leaving the node.
