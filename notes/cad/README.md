# CAD

| abbr. | stand for                        | cn                 |
| ----- | -------------------------------- | ------------------ |
| CAD   | Computer-Aided Design            | 计算机辅助设计     |
| MCAD  | Mechanical Computer-Aided Design | 机械计算机辅助设计 |
| ECAD  | Electronic Computer-Aided Design | 电子计算机辅助设计 |

---

| Spec | FreeCAD                                | KiCad                              |
| ---- | -------------------------------------- | ---------------------------------- |
| 领域 | 参数化 3D CAD、机械、产品设计、建筑    | EDA / 电子 CAD                     |
| 对象 | 外壳、支架、零件、装配结构             | 电路原理图、元件封装、PCB          |
| 信息 | 几何形状、尺寸、约束、模型历史         | 元件、引脚、电气连接、焊盘、铜线   |
| 操作 | 画带尺寸约束的草图，生成和修改三维零件 | 放置电路符号、连线、摆放元件、布线 |
| 扩展 | `.FCStd`                               | `.kicad_sch`、`.kicad_pcb`         |

- FreeCAD
  - 给板子做尺寸模型，设计外壳和安装支架
  - 设备外壳、安装支架、收纳盒、带螺丝孔的零件
- KuCad
  - 重建原理图，设计转接板或新电路板
- Blender
  - 摆件、人物、动物、装饰、自由曲面
